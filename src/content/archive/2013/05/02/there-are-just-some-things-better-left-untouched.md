for nothing else will happen when you try to change them;

there are just some things better left untouched
because they always go back the same place anyway
there are just some things better left undone
because finishing it would make it more gone
there are just some things better left unsaid
because the silence can embrace the warmth of your soul
there are just some things better left unthought
because what's the use of thinking if when you won't do it
there are just some things better left unfinished
because
