Since [Microsoft announced that it's discontinuing Sunrise Calendar](http://www.theverge.com/2016/5/11/11657960/microsoft-shutting-down-sunrise-app), I'm trying to look for another calendar app that I can use that's similar to it.

*For now, I don't want to use Google Calendar because I don't want to be limited to just Google. I really liked the fact that Sunrise Calendar integrated a lot of other platforms in it, which is what made it so useful for me.*

For now, I found some apps from [alternativeto.net](http://alternativeto.net/software/sunrise-calendar/):

	- WAVE Calendar [[website](http://www.wavecalendarapp.com/)] [[Google Play](https://play.google.com/store/apps/details?id=com.esites.ecal)]

	- Etar [[Google Play](https://play.google.com/store/apps/details?id=ws.xsoh.etar)]

And some of my friends also suggested other apps:

	- aCalendar+ [[website](http://www.tapirapps.de/en/home.htm)] [[Google Play](https://play.google.com/store/apps/details?id=org.withouthat.acalendarplus&hl=en)]

	- Today Calendar [[Google Play](https://play.google.com/store/apps/details?id=com.underwood.calendar_beta&hl=en)]

	- Business Calendar 2 [[website](http://www.businesscalendar.de/)] [[Google Play](https://play.google.com/store/apps/details?id=com.appgenix.bizcal&hl=en)]

I have not yet checked *any *of the things I've listed above. I'm going to test them all out within the next few weeks or so. Maybe do a background check on each one first, then just pick which ones I'd really want to test out.

I want to see if any of these apps can work on a phone with these specs:

	- Android version 4.2.2 (Jellybean)

	- Total internal storage: 1.27 GB

	- Total memory card storage: 7.28 GB

	- Total phone space: 672 MB

(Also, my current phone's an O+ 8.91. It's kind of old.)

Let's see what happens.
